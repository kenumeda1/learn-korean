How this works

Type a Korean word. We suggest noun (명사), adjective (형용사), or verb (동사) as you type. Press Enter to classify.

Add with the button, or ⌘ Enter / Ctrl Enter to add using the suggested role above (or noun if classification is not ready yet). Then build your library (at least one noun and one verb), generate an English prompt, type your Korean translation, and use Check for feedback.
